# shared/ is the universal source of truth

Five surfaces (storefront, account, billing, pricing, portal) are being built in parallel by five agents against prompts/SHARED_CONTRACT.md. This folder is what keeps them from working over each other. It was created at the mid-build check-in on 2026-09-10, after every surface finished Phase 3.

Read in this order:
1. CONTRACT_ADDENDUM.md. Normative. Extends the contract and resolves every conflict found so far. Wins over the contract and over any DECISIONS.md.
2. OWNERSHIP.md. Which surface writes which entity, owns which screen, and proves which cross-surface flow.
3. STATUS.md. Generated by checkin/build_status.py. Progress, build and test state, drift flags per surface.
4. DECISIONS_SYNTHESIS.md. Evidence behind the addendum, with citations into each DECISIONS.md, and open questions for Kevin.

Canonical code:
- types.ts. The one types file. billing/src/types.ts is identical to it today.
- tokens.css. The one token set, read from Paper. Adopt only at polish.

Rules:
- Surface agents never write into shared/. Requests go in the surface's DECISIONS.md under "Requests for shared/".
- Regenerate STATUS.md with: python3 checkin/build_status.py
- Open the check-in hub with: bash checkin/start.sh (or the "checkin" launch configuration)
